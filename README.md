## About the site

A single static `index.html`. It has no build step and no dependencies apart from Google Fonts.

- Editorial layout with a sticky sidebar and section nav that highlights the current section as you scroll
- Light and dark themes that follow the system setting, plus a manual toggle that is remembered
- Scroll-reveal animations and a soft cursor spotlight, both turned off when the system asks for reduced motion
- Works on phone screens

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
